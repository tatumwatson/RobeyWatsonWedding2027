# Wedding website

## What's in here

- `index.qmd`, `schedule.qmd`, `travel.qmd`, `funds.qmd`, `rsvp.qmd`, `faq.qmd`, `photos.qmd`, `story.qmd` —
  site's pages.
- `assets/theme.scss`, `assets/styles.css` — color palette
  and layout. 
- `assets/rsvp.js`, `assets/rsvp-config.js` — RSVP widget.
- `rsvp-backend/` — Google Sheet + Apps Script backend for RSVPs.
  **Start here**: `rsvp-backend/README.md` Setup process followed. 
- `.github/workflows/publish.yml` — automatically rebuilds and publishes
  the site every time pushed to `main`.
